vidopt — production package (Windows, offline, train + compress)
===============================================================

OFFLINE WORKFLOW (train once, compress many times)
--------------------------------------------------
1. Extract the production / project zip
2. Run install.bat  (extracts vendor-windows-x64.zip + installs vidopt)
3. Copy training videos into video\corpus\  (if not already in the zip)
4. Train:    vidopt.bat train video\corpus --config cpu --encoder ENCODER --level LEVEL --cpu-workers 0 --resume
5. Inspect:  vidopt.bat inspect
6. Compress: vidopt.bat compress in.mp4 -o out\out.mp4 --encoder ENCODER --level LEVEL --verify --resume

LEVEL mapping:
  level 1 -> VMAF 85
  level 2 -> VMAF 89
  level 3 -> VMAF 93

Resume (after Ctrl+C or crash):
  Re-run the SAME train command with --resume.
  Skips finished segment searches (search_records.jsonl) and reuses trial cache (trials.sqlite).

Example (recommended CPU path):
  vidopt.bat doctor
  vidopt.bat train video\corpus --config cpu --encoder libsvtav1 --level 2 --cpu-workers 0 --resume
  vidopt.bat inspect
  vidopt.bat compress in.mp4 -o out\out.mp4 --encoder libsvtav1 --level 2 --verify --resume

Windows offline zip (full train + compress):
  scripts\prepare_offline_bundle.bat
  install.bat
  scripts\pack_production.bat --with-models
  -> dist\vidopt-offline-windows-x64.zip

Windows offline zip (build on connected PC):
  scripts\prepare_offline_bundle.bat
  install.bat
  scripts\pack_production.bat --with-models
  -> dist\vidopt-offline-windows-x64.zip  (contains vendor-windows-x64.zip inside)

Offline PC:
  extract zip -> install.bat -> vidopt.bat doctor -> train / compress

Full project backup (vendor compressed inside project zip):
  scripts\pack_project.bat --with-models
  -> dist\vendor-windows-x64.zip
  -> dist\vidopt-project-windows-x64.zip

Pack compress-only (optional — encode only, no train on that PC):
  scripts\pack_compress.bat
  -> dist\vidopt-compress-windows-x64.zip
  Guide: COMPRESS_GUIDE.md

Search algorithms (train only — compress uses the trained model):
  default (CLI)   search.strategy=boundary
  others          aq_then_crf, coordinate, sample, bayes, tpe, cmaes
  Full catalog: USAGE.md section 2.4

Defaults: encoder=libx265, cpu-workers=4, gpu-workers=0

Models after training: models\<encoder>\target_<VMAF>\
Training logs: <work_dir>\logs\vidopt.log
Checkpoints:   <work_dir>\search_records.jsonl, runs\cache\trials.sqlite

Bundled repair kit (no network needed):
  vendor\installers\python-3.11.9-embed-amd64.zip
  vendor\wheelhouse\*.whl
  vendor\ffmpeg\bin\ffmpeg.exe + ffprobe.exe
If damaged: install.bat — see REPAIR.txt
