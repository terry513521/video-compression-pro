vidopt — ready-to-run package
=============================

OFFLINE WORKFLOW (train once, compress many times)
------------------------------------------------
1. Install / extract (no network after setup)
2. Copy training videos into video/corpus/
3. Train:  vidopt dev video/corpus --config cpu --encoder ENCODER --resume
4. Inspect: vidopt inspect
5. Compress: vidopt compress in.mp4 -o out/out.mp4 --target 89 --encoder ENCODER

Full guide: USAGE.md sections 2.9 (offline train) and 3.6 (production deploy)
Windows detail: OFFLINE_GUIDE.md
Linux detail: LINUX.md section 6

Linux (CPU-only):
  ./install.sh
  copy training videos into video/corpus/
  ./vidopt.sh doctor --config cpu
  ./vidopt.sh dev video/corpus --config cpu --encoder libsvtav1 --cpu-workers 0 \
    --set search.targets='[89]' --set paths.work_dir=runs/production --resume
  ./vidopt.sh compress in.mp4 -o out/out.mp4 --target 89 --encoder libsvtav1 --verify

Search algorithms (dev mode only — compress uses the trained model):
  default          search.strategy=aq_then_crf   recommended for production
  others           coordinate, sample, bayes, tpe, cmaes
  Full catalog: USAGE.md section 2.4
  Optional: widen VMAF labels during dev with --set search.targets='[85,89,93]'
    (research only — days; models under models/matrix/)

Windows offline zip:
  vidopt.bat doctor
  vidopt.bat dev video\corpus --encoder libx265 --cpu-workers 4 --resume
  vidopt.bat compress in.mp4 -o out\out.mp4 --target 89 --encoder libx265 --verify
  Pack compress-only (models, no corpus):
    Linux:   ./scripts/pack_compress.sh
    Windows: scripts\pack_compress.bat
  Guide: COMPRESS_GUIDE.md

Defaults: encoder=libx265, cpu-workers=4, gpu-workers=0

Models after training: models/<encoder>/  (one bundle; pass --target at compress time)
Training logs: <work_dir>/logs/vidopt.log
Matrix logs: runs/matrix/logs/  (see INDEX.txt)

Bundled repair kit (no network needed):
  vendor\installers\python-3.11.9-embed-amd64.zip
  vendor\wheelhouse\*.whl
  vendor\ffmpeg\bin\ffmpeg.exe + ffprobe.exe
If damaged: install.bat — see REPAIR.txt
